Cómo funciona

Documentación viva, no PDF de 80 páginas.

Cuatro piezas para que tu equipo técnico no pierda un sprint integrando: docs auto-generadas, ejemplos ejecutables en el navegador, SDKs oficiales y un changelog público con avisos antes de cada cambio.

01 · Auto-generada

Siempre al día. Imposible que mienta.

Cada despliegue de Pasify regenera la documentación a partir del esquema OpenAPI 3.1. Si un campo cambia o aparece un endpoint nuevo, lo ves en docs antes de que tu integración se entere. Schema descargable para que tu equipo lo importe en su propio generador o servidor de mocks.

  • Generación desde OpenAPI 3.1 en cada commit a producción
  • Schema completo descargable en YAML y JSON
  • Diff visible entre versiones, sin abrir releases notes
  • Mocks generables con un solo comando de tu CLI
· openapi.yaml · 247 endpoints
02 · Ejemplos ejecutables

Prueba sin salir de la página.

Cada endpoint trae cinco ejemplos — cURL, JavaScript, Python, PHP y Ruby — y un botón «Probar» que ejecuta la petición contra el sandbox con datos sintéticos en menos de un segundo. Tu equipo no sale de la documentación para validar que el endpoint hace lo que cree, y la respuesta queda guardada en su sesión para comparar.

  • Ejemplos copy-paste en cinco lenguajes con tu API key
  • Botón «Probar» con respuesta real desde el sandbox
  • Histórico de tus últimas peticiones de la sesión
  • Variables de plantilla con tus IDs reales precargados
· /v1/tickets · probar
03 · SDK y colecciones

Trabaja con la herramienta que ya usas.

SDKs oficiales en JavaScript, Python, PHP, Ruby y Go publicados en npm, PyPI, Composer, RubyGems y Go modules. Colección Postman e Insomnia mantenidas por nosotros, no por la comunidad. Si tu equipo es de IDE plugins, tenemos extensiones para VS Code y JetBrains que autocompletan tipos del esquema actual.

  • SDKs oficiales mantenidos en cinco lenguajes
  • Tipado completo en TypeScript y Python
  • Colección Postman e Insomnia con un toque desde docs
  • Plugins VS Code y JetBrains con autocompletado del esquema
· sdks · 5 lenguajes
04 · Changelog y avisos

Sin sorpresas en mitad de tu integración.

Changelog público con cada cambio, deprecación con seis meses de aviso y RSS para que tu equipo se entere antes que tu integración se rompa. Para los cambios grandes — nueva versión mayor, nuevos campos requeridos — mandamos correo a la persona técnica que firmó el contrato.

  • Changelog público con commit hash y enlace al ticket
  • Deprecaciones con seis meses de aviso y guía de migración
  • RSS y webhook al canal Slack que tu equipo elija
  • Aviso por correo a la persona técnica de contrato

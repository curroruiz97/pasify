01 / Decisiones de identidad

Tagline, voz y mantra de marca.

La triada que define cualquier copy de Pasify: cálida, confiada, con criterio. Habla de tú, sin gritar.

Tagline elegido

"El pase a tu mejor noche."

Activa el doble sentido del nombre — pase como acceso, y como gesto de pasar adentro. Funciona como CTA emocional para B2C y como promesa de plataforma para B2B. Las alternativas ("Vende, gestiona, vibra" / "Pasa adentro. Sin fila, sin papel, sin fricción") quedan como secondary copy para hero rotativos y campañas.

Sub-taglines de campaña
  • · Para locales: Vende más. Cobra menos comisión. Dueño de tu data.
  • · Para asistentes: Sin fila, sin papel, sin fricción.
  • · Para promotores: Tu link. Tu lista. Tu comisión.
Personalidad

El primo nocturno de Claude.

Premium pero no frío. Cálido pero no naïve. Editorial pero no acartonado. Como si tu local favorito tuviera un equipo de software detrás — y ese equipo tuviera buen gusto.

09 / Plan de páginas

13 páginas, 3 bloques, 1 sistema.

Lo que viene tras tu OK. Cada bloque es una fase, con pausa intermedia para iterar.

Bloque 1 — Marketing B2B
  1. 01 Home — hero + propuesta + social proof + módulos + testimonios + CTA final
  2. 02 Producto — ticketing, RRPP, mesas, escáner QR, CRM, analytics expandidos
  3. 03 Pricing — Starter / Pro / Enterprise + comparativa + ROI calculator + FAQ
  4. 04 Casos de éxito — grid + 1 case study extendido con métricas
  5. 05 Promotores / RRPP — landing dedicada con sistema de comisiones
Bloque 2 — Marketplace B2C
  1. 06 Descubre eventos — grid filtrable por ciudad, fecha, género, precio
  2. 07 Ficha de evento — hero media + lineup + mapa + ticket selector + urgencia
  3. 08 Ficha de local — galería + próximos eventos + reseñas
  4. 09 Checkout — 3 pasos (selección → datos → pago) + resumen sticky
Bloque 3 — Soporte
  1. 10 Sobre nosotros — manifiesto + equipo + métricas globales
  2. 11 Recursos / Blog — listado + plantilla de artículo
  3. 12 Contacto / Demo — formulario calificador + Calendly embebido
  4. 13 Footer global + plantilla legal (privacidad, términos, cookies)
Cómo entrego
  1. Fase 2 — Home → Producto → Pricing // pausa
  2. Fase 3 — Marketplace → Ficha evento → Checkout // pausa
  3. Fase 4 — Casos → Promotores → Sobre / Demo / Footer

Cada página será un artifact React+TS+Tailwind autocontenido, mobile-first 375px, con microinteracciones y datos realistas (Madrid, Barcelona, Ibiza, Sala Apolo Lab, Mondo Disko, Florida 135...). Tras cada fase paro y espero feedback.
